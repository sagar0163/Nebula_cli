# Discord Setup & Community Strategy

## Channels Setup

- `#welcome-rules`: Automated welcome messages and server rules.
- `#general`: General discussion about Nebula-CLI, terminal tools, and AI.
- `#help`: Troubleshooting and user support.
- `#plugin-dev`: Discussion about writing custom plugins and extensions.
- `#healing-patterns`: A dedicated channel for users to share and discover useful healing patterns.
- `#core-dev`: Coordination for core contributors and maintainers.

## Launch Plan (Week 1)

1. Create the Discord server and configure roles (Admin, Contributor, Member).
2. Set up basic moderation bots.
3. Add the Discord invite link to the GitHub README and CONTRIBUTING.md.
4. Announce the server on Twitter and other initial channels.

## Growth Strategy (Months 1-3)

- Encourage users to join via CLI notifications after successful installations.
- Host "Pattern of the Week" highlights.
- Offer custom roles/badges for active contributors.
- Work towards 100 members in Month 1 and 500 by the end of Q1.
