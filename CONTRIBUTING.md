# Contributing to Nebula-CLI

First off, thank you for considering contributing to Nebula-CLI! It's people like you that make Nebula-CLI such a great tool.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone the repository** locally: `git clone https://github.com/your-username/Nebula_cli.git`
3. **Install dependencies**: run `npm install` (or `yarn install`).
4. **Create a new branch**: `git checkout -b my-feature-branch`.

## Making Changes

- Ensure your code follows the existing style. We use Prettier and ESLint.
- Run tests before pushing: `npm test`.
- Add tests if you are adding new functionality.
- Write clear, descriptive commit messages.

## Submitting a Pull Request

1. Push your branch to your fork on GitHub.
2. Open a Pull Request from your fork to the `main` branch of Nebula-CLI.
3. Fill out the PR template completely.
4. Wait for a maintainer to review your PR. We aim to review PRs within 24 hours.

## Good First Issues

If you're new to the project, look for issues labeled `good first issue` or `help wanted`.
